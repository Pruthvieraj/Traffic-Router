# flask-limiter adds basic per-IP rate limiting to /api/solve and
# /api/solve_fleet (20 requests/minute) so a public demo URL can't be
# trivially hammered. It's automatically disabled while running under
# pytest (see app.py) so the test suite is never rate-limited.

# gunicorn is only needed when deploying app.py to a cloud host (Render,
# Railway, etc.) — see the "Deploy to the cloud" section in README.md.
# It's unused for local runs (python3 app.py uses Flask's own dev server).
#
# dwave-system is NOT listed above on purpose — it's only needed if you
# run run_on_real_quantum_hardware.py (a one-time pitch-deck credibility
# script, not part of the app). Install it separately when you want that:
#     pip install dwave-system
#
# pytest is also NOT listed above — it's a dev-only tool for running the
# tests/ suite, not something the app or a deploy needs. Install it
# separately to run tests:
#     pip install pytest && pytest tests/ -v
#
# The frontend helper tests (tests/frontend/) need only Node.js 18+ (for
# its built-in test runner) — no npm install, no extra Python dependency:
