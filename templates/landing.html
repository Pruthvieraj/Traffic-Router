QubitRoute Quantum-inspired

SIH 2026 · PS SIH26137

Constraint-aware route optimization, benchmarked honestly against classical routing

Given a set of stops and a road network whose travel times change with the time of day, this project formulates the visiting-order problem as a QUBO and solves it with a simulated-annealing sampler that mimics quantum-annealing search behavior — alongside a classical baseline and an honest benchmark of where each one actually wins.
